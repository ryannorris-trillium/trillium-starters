# Code Hunt

Six levels. Each one prints a code word when you solve it. Write each code word
on your paper sheet. In order, the six words make a sentence.

Run a level from the terminal:

```
python3 hunt/level1.py
```

Then `level2.py`, and so on. Do them in order.

| Level | What you do |
|---|---|
| 1 | Run it |
| 2 | Fix one missing character |
| 3 | Change one value |
| 4 | Fix a loop |
| 5 | Finish two functions |
| 6 | Build a text adventure |

Rules:

- Only edit above the line that says **Do not edit below this line**.
- If a level prints an error, read the last line of it first. It names the file,
  the line number, and what Python could not do.
- Stuck for more than five minutes? Raise your hand.

Commit your work at the end of class.
