# JavaScript canvas game

1. Right-click `web-canvas/index.html` → **Show Preview** (Live Preview extension), or run `npx --yes serve --listen 3000 web-canvas` and open port 3000.
2. Arrow keys move the circle. Edit `index.html`, save, the preview refreshes.

No build step, no install. This is the lightest way to make a browser game.

If the tab opens but nothing loads: in the **Ports** tab, right-click port 3000 → **Port Visibility** → **Public**, then refresh. A private port blocks the page's own file requests.
